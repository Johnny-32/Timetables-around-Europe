Hours as one column

Introduction

This is a pretty popular timetable style and for a good reason, it's intuitive to read and it's ideal for a single stop timetable.

Examples

Vienna

Vienna has a separate timetable for each route and each stop gets it's own page in a pdf file. On top we can see a list of stops with approximate travel times for each stop. The timetable itself shows all timetable periods on one page.

Amsterdam

Amsterdam has a separate timetable for each route and each stop. On the left we can see a list of stops. The timetable itself shows all timetable periods on one page.

Warsaw

Warsaw has a separate online timetable for each route and each stop. Unfortunately it doesn't have a pdf version, I think it would be easy to make it.

Munich (kinda)

Munich has a separate timetable for each line. This one is pretty different from the rest, first column represents hours and the rows departures for each stop, when departures in a couple hours have the same minutes they are grouped together to shorten the timetable.
